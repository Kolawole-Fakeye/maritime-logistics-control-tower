
## 🚢 Maersk West Africa Fleet Control Tower
### Logistics Telemetry & Performance Engine

A specialized full-stack data system designed to track maritime fleet operations, monitor demurrage financial leakages, and log carbon intensity ratings (CII) across critical West African supply chain hubs (Apapa, Tin Can Island, Tema, and Luanda).

### 🚀 Production Deployment
* **Interactive Live Dashboard:** [Maersk West Africa Control Tower](https://maritime-logistics-control-tower-t65umbypcmqusncpetrfyo.streamlit.app/)

### 📊 System Features
* **KPI Matrix Monitoring:** Live calculation of total voyages tracked, average port turnaround times, accrued demurrage penalties, and carbon footprint mass (MT CO2).
* **Operational Bottleneck Analytics:** Automated data grouping by arrival port to isolate high-risk delays.
* **Financial Leakage Tracking:** Aggregated metric views tracking demurrage costs against specific vessels to protect supply chain margins.
* **Decoupled Architecture Ready:** Contains full-stack asset pathways featuring a local mock data engine and structured FastAPI REST routing definitions.

### 🏗️ Architecture Stack
* **Frontend UI:** Streamlit Core using native, zero-dependency data visualization engines for high-speed cloud container compilation.
* **Backend Asset:** FastAPI REST gateway schemas utilizing optimized numpy and pandas processing rules.
* **Data Layer:** Lightweight text-based CSV serialization pathways ensuring instant cold-start times.
